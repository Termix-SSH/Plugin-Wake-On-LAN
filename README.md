</div>

<br />

## Overview

Wake-on-LAN sends a magic packet to wake a host up.

Read the [docs](https://docs.termix.site/plugins/wake-on-lan) to set it up and use it.

<br />

## Features

- Wake a host in one click
- Wake a host before a remote desktop connection
- Wake a host from an automation

## Support

Bugs and ideas for Wake-on-LAN go in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Wake-On-LAN/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Wake-On-LAN/issues/new?template=feature_request.yml). Report an issue on the plugin's page in the Plugins tab fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Add as much detail as you can, in English if possible. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
